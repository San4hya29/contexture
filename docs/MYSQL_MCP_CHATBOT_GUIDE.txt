============================================================
  MySQL MCP Chatbot — How to Run
============================================================

Prerequisites:
  - Docker installed
  - Python 3 with virtual environment (.venv)
  - Project root: /home/niteesh/contexture-clean


Step 1: Start MySQL (Docker)
──────────────────────────────────
  docker run -d --name contexture-mysql \
    -e MYSQL_ROOT_PASSWORD=root \
    -p 3306:3306 \
    mysql:8.0

  Wait a few seconds for MySQL to be ready. Verify:
  docker exec contexture-mysql mysql -uroot -proot -e "SELECT version()"


Step 2: Load E-commerce OCS Schema
───────────────────────────────────
  docker exec -i contexture-mysql mysql -uroot -proot < scripts/mysql/ecommerce_ocs_schema.sql

  This creates:
    - Database: ecommerce
    - Tables: customers (5 rows), products (5 rows), orders (7 rows)


Step 3: Start the MySQL MCP Server
────────────────────────────────────────
  source .venv/bin/activate
  python3 pkg/agents/mysql/server.py --transport sse --port 8005

  Keep this running in a separate terminal.
  Server will be available at: http://localhost:8005/sse

  MCP Tools exposed:
    my_list_databases, my_list_tables, my_describe_table,
    my_execute_query, my_get_table_stats, my_get_db_stats,
    my_get_slow_queries, my_check_db_health


Step 4: Run the NL Chatbot (in another terminal)
─────────────────────────────────────────────────
  source .venv/bin/activate
  python3 scripts/mysql/chatbot.py

  The chatbot connects to MySQL through the MCP Server (not directly).

  Data flow:
    User NL Query
      → Chatbot (NL → SQL via Ollama or offline regex)
      → FastMCP Client (SSE transport)
      → MySQL MCP Server (port 8005)
      → my_execute_query tool
      → MySQL DB (port 3306)
      → Results → Formatted Table → Terminal
